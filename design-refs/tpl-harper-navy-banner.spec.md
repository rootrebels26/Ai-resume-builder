# Spec: tpl-harper-navy-banner (`pro-harper-navy-banner`)

## Page
- Target size: A4 (`794 x 1123 px`). Full-bleed dark navy top header band (`#293565`), white `#ffffff` body below with `28px` horizontal/bottom padding.

## Structure
- Header block (full-bleed `#293565`, `24px 28px` padding):
  - Left: `h1` white UPPERCASE bold name, light-slate/white role subtitle, 2-column contact grid (phone, email, linkedin, location).
  - Right: Circular photo (`84px x 84px`) with subtle ring (`border-2 border-white/30`).
- Body: `60% / 40%` two-column layout (`gap: 22px`).
  - Left column (`60%`): `SUMMARY`, `EXPERIENCE` (role bold, company `#293565`/`#2563eb`, date + location row, bullets).
  - Right column (`40%`): `KEY ACHIEVEMENTS` (icon + bold title + description, dashed bottom separator), `SKILLS` (underlined tag chips in 2-col/wrap flex), `EDUCATION`, `TRAINING / COURSES`, `LANGUAGES` (5 circular dots right-aligned).

## Typography
- Heading & Body: `Inter` / `Plus Jakarta Sans`.
- Name: `24px` bold uppercase white.
- Section headings: `11px` bold uppercase `#293565`, `2px solid #293565` bottom border.

## Color
- Primary / Banner bg: `#293565`
- Accent: `#3b82f6` / `#293565`
- Text: `#1e293b`, Muted: `#475569`, Border: `#cbd5e1`, Background: `#ffffff`.
