# Spec: tpl-joanna-mint-sidebar (`pro-joanna-mint-sidebar`)

## Page
- Target size: A4 (`794 x 1123 px`), `#ffffff` background, `24px` outer padding.

## Structure
- Two-column layout: `32%` left sidebar + `68%` right main column (`gap: 24px`).
- Left sidebar (`32%`):
  - Top: Circular photo (`104px x 104px`) framed by soft organic mint blob backdrop (`#9fcdb1` / `#d1fae5`).
  - Sections (with small mint square icon badge `#8dbdad` beside heading): `CONTACTS` (vertical list with mint icons), `SKILLS` (dot-separated text), `KEY ACHIEVEMENTS` (bullet + bold title + description), `TRAINING / COURSES` (title + description).
- Right main column (`68%`):
  - Top header: Light-weight uppercase name (`#1e293b`, `font-light` / `300`, `26px`, tracking `0.05em`), followed by a rounded mint pill banner (`#9fcdb1`, `rounded-full` / `rounded-xl`, `#14532d` uppercase text) for `professionalTitle`.
  - Sections (with small mint square icon badge beside heading + thin bottom rule): `SUMMARY`, `EXPERIENCE` (Company bold left + location right; Role below left + dates right; bullets), `EDUCATION` (institution bold + location right; degree + dates right).

## Typography
- Heading & Body: `Poppins` / `Inter` (`font-light` on name for editorial feel).
- Section headings: `11px` bold uppercase `#1e293b`.

## Color
- Primary: `#2f6f55`
- Accent / Mint pill: `#9fcdb1` (soft mint), `#8dbdad` (icon badge), `#14532d` (high-contrast pill text >= 4.5:1)
- Text: `#1e293b`, Muted: `#475569`, Background: `#ffffff`.
